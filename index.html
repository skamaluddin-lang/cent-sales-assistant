Objection Assistant

“It is expensive.”

Ask which exact package the customer is comparing with CENT, then compare the scope line-by-line rather than comparing only the headline price.

“I only want blood tests.”

Clarify whether the customer wants laboratory testing only or a comprehensive preventive assessment including imaging, cardiac and body-composition components.

“Another package is cheaper.”

Ask for the exact package name and inclusions. A lab-only package and a package combining MRI, CT, DEXA and biomarkers are not automatically like-for-like.
