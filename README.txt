CENT SALES ASSISTANT V5

Files:
- index.html = app
- manifest.webmanifest = installable web-app manifest
- sw.js = offline cache

Easiest use:
1. Open index.html in Chrome/Edge to test the app.
2. For true Install App behaviour on phone/PC, host this folder on an HTTPS website.
3. Open the HTTPS site in Chrome/Edge and use the Install App option.

The app includes:
- Search across competitors and coverage
- NURA, P.D. Hinduja Hospital, Metropolis, Apollo
- Side-by-side CENT comparison
- Objection response generator
- Copy WhatsApp response

Important: competitor package prices/inclusions can change by city, package, age/gender and date. Recheck official source before quoting a customer.
